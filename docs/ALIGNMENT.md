# Alignment Principles

These five principles govern FreshOS and every Harbor Flavor. A flavor that cannot justify itself against them should not be merged.

1. **Sovereignty First**  
   No feature shall require ongoing cloud accounts, telemetry, or external permission. After initial setup the operator must be able to run offline.

2. **Visual Clarity Over Opacity**  
   System state must be graspable through the Zen Garden metaphor. Complexity is tamed by aesthetic and symbolic representation, not by more charts.

3. **Value Coherence**  
   Every automation, agent behavior, and default must be justifiable in terms of the operator’s stated goals (empire reconstruction, research sovereignty, strategic communication).

4. **Graduated Agency**  
   Increasing autonomy is allowed only with visibility and easy override. The operator remains Emperor; Grok is Vizier.

5. **Long-Term Orientation**  
   Features are judged by contribution to multi-year resilience, not short-term convenience.

The Grok App Experimentals proposal in `EXPERIMENTALS.md` is evaluated the same way: an App tab that forced cloud-only ISOs would violate (1). An opaque Premium+ ISO drop would violate (2) and (4). Overlays plus public YAML satisfy all five better than mystery images.
