# Research Harbor (example flavor)

A community-style overlay that treats FreshOS as a private research station.

- Modules on: Research, Archives, Crew
- Modules off: Finance, Publishing
- Visualizer: moss-forward, less gold, fewer lanterns
- Packages: ripgrep, fd, pandoc, sqlite, jq, git

Apply:

```bash
./scripts/apply-flavor.sh flavors/examples/research-harbor
```
