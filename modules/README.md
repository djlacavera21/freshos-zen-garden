# Empire modules

Each directory is a wing of the sovereign operation described in the whitepaper.
Phase 1 ships contracts and placeholders, not full pipelines.

| Wing | Intent |
|---|---|
| `research` | Pipelines, source verification, synthesis |
| `design` | Emblems, posters, visual production |
| `publishing` | Distribution, archives of outgoing work |
| `war-room` | Scenarios, alliance maps |
| `finance` | Resource tracking, sovereignty economics |
| `archives` | Long memory |
| `crew` | Operator environment |

A Harbor Flavor enables or disables these IDs.
