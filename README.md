## Vision

FreshOS is not another generic Linux remix or AI agent framework.  
It is a **sovereign automation substrate** designed so that every layer — from boot splash to agent orchestration — serves the operator’s core values of steadfastness, research sovereignty, content sovereignty, strategic communication, and multi-year empire reconstruction (inspired by the Holy Byzantine model of resilient, values-coherent civilization).

The centerpiece is the **Zen Garden Visualizer**: system state rendered as a living, meditative Japanese-inspired garden rather than anxious dashboards and scrolling logs.

- Raked sand = CPU / system load  
- Stones & rocks = memory, processes, and knowledge archives  
- Stone lanterns & bridges = network connections, external alliances (X, devices, partners)  
- Central glowing Grok orb = the aligned intelligence at the heart of the empire  

Grok acts as **Vizier** (calm strategic advisor and orchestrator). The human operator remains **Emperor**.

## Quick Start (for developers / early experimenters)

1. Clone this repository.  
2. Read `docs/WHITEOBAPER.md` and `docs/ALIGNMENT.md`.  
3. Review `scripts/customize-freshos.sh` (the one-command transformation).  
4. Prototype the visualizer locally: open `visualizer/index.html`.  
5. For full .iso: follow `iso-build/README.md` (requires Linux Mint 22.3 base + Cubic).

**Important**: This project does **not** currently ship a pre-built multi-GB ISO. Users build their own from the base Mint ISO using the provided scripts. This preserves sovereignty, reduces distribution liability, and keeps the project lightweight.

## Harbor Flavors (Community Variants)

“Harbor” here refers to community-created overlays / flavors of the base FreshOS Zen Garden:

- Different module emphasis (Research-heavy, Finance-heavy, Propaganda/Design-heavy, Air-gapped TUI, etc.)  
- Custom themes, Plymouth variants, default agent prompts  
- Pre-integrated research archives or toolchains  
- Specialized packages or systemd units  

See `flavors/` for the overlay format and contribution guidelines.  
Premium+ upload + curation is a proposed future Grok App feature, not implemented here.

## Alignment Principles (Summary)

1. **Sovereignty First** — Offline-capable after setup; no mandatory cloud accounts or telemetry.  
2. **Visual Clarity Over Opacity** — Zen Garden metaphor over traditional dashboards.  
3. **Value Coherence** — Every default and agent behavior must serve the operator’s stated empire goals.  
4. **Graduated Agency** — Operator remains Emperor; Grok is Vizier with clear visibility and override.  
5. **Long-Term Orientation** — Features judged by multi-year resilience contribution, not short-term convenience.
